I would like to build an Android app to help prepare those that attend USCIS Civics test.  Actual questions and related text book are in the references folder.

Here are the requirements for the app:
* Run on Pixel 7a, Pixel 8 etc
* Have to modes, learn mode and test mode.
* Store the test results locally on the device, have a max limit on the storage size and/or time to store the results
* Prompt a question daily and give preferences to those questions that has most wrong answers
* A full test should contain 20 questions
* Provide additional information on the correct answer
* Make it fun to learn these
* Keep the app local, no need for pushing metrics to a server side component
